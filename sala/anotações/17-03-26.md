INSTALANDO NPM E TS:
- abrir o terminal com *Crtl Shift '*

```
npm i -g typescript //Instala globalmente ts
npm i -g npm //Instala npm global
npx tsc -v //Versão
npm -v //Versão
```

CONFIGURAÇÕES INICIAIS:

- terminal
```
npx tsc -init //cria o tsconfig.js
npx tsc {nome_arqv}.ts //cria o arquivo js correspondente


node {nome_arqv}.js //rodar arquivo
npx tsc -w //ficar sempre atualizando 
```
